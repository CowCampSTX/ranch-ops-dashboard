# Project

The living files that say where the project stands. Update them in the same pull request as the change they
describe.

| File | What it holds |
|---|---|
| [STATUS.md](STATUS.md) | What is merged, what is open, what comes next, and the questions waiting on the owner |
| [DECISIONS.md](DECISIONS.md) | The owner's decisions, newest first, each with who decided, when, and where the detail is |

Read STATUS.md at the start of every session, and check DECISIONS.md before deciding something again
([AGENTS.md](../../AGENTS.md#start-of-every-session)). The Drive copy is the folder `project`.
